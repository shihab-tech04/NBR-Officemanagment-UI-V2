# Master Prompt — Improve Country-Specific Phone Validation and Fix Autofill Color

Work inside **NBR-eReturn-Office Management UI (58)**. Make only these focused fixes.

## 1. Show specific country-based phone errors

Update:

* `src/app/utils/phoneNumber.ts`
* `src/app/components/special-registration/SpecialRegistrationForm.tsx`
* EN/BN `specialRegistration.json`

Keep using `libphonenumber-js/max` and `validatePhoneNumberLength()`. Validate only the national digits entered after the existing country code.

Add a cached helper:

```ts
getPhoneLengthRule(countryCode)
```

It must determine all supported national-number lengths by checking lengths `1–20` with `validatePhoneNumberLength()`.

Return:

```ts
{
  allowedLengths: number[];
  minDigits: number;
  maxDigits: number;
}
```

Do not manually maintain country phone lengths.

Replace generic messages such as:

* Phone number is too short.
* Phone number is too long.
* Phone number has an invalid number of digits.

With one precise translated message:

**English**

```text
For {{country}}, enter {{allowedLengths}} digits after {{dialCode}}. You entered {{enteredDigits}}.
```

Example:

```text
For Bangladesh, enter 10 digits after +880. You entered 11.
```

For multiple valid lengths:

```text
For Andorra, enter 6, 8, or 9 digits after +376. You entered 7.
```

Format consecutive lengths as a range where appropriate, such as `6–10 digits`.

Use the localized country name in EN/BN.

Do not count the country code as part of the entered digit length.

## 2. Stop input after the country maximum

```ts

```

Pass:

```tsx
maxLength={phoneRule?.maxDigits}
```

to the existing `AppPhoneField`.

Also guard `handlePhoneChange()`:

```ts
if (candidate.length > phoneRule.maxDigits) {
  setPhoneLengthError(countrySpecificMessage);
  return;
}
```

This must:

* Prevent typing beyond the maximum
* Prevent oversized pasted values
* Keep the previous valid field value
* Preserve leading zeroes
* Continue supporting Bangla digits
* Allow deletion and correction
* Recalculate the maximum when the country changes

If an existing number becomes too long after changing country, do not truncate it automatically. Show the country-specific error and let the user correct it.
